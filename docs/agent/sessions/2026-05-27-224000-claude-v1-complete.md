## Decisions

Durable, indexed in `docs/agent/DECISIONS.md`:

- **Translation provider switched from DeepL Free to Google Cloud
  Translation v2.** DeepL Free closed signups during the build.
  Google offers a recurring ~500K NMT chars/month free credit (not
  a 12-month trial) which matches v1 needs. Provider interface
  unchanged.

Operational (not promoted to DECISIONS index — they're
implementation details captured in commits and the task file):

- API-key auth chosen over service-account JSON. Simpler for a
  single-process bot; key is restricted to Translation API only.
- Collapsible panel as the default UX (only `⚙ Change language`
  shown). Click to expand; `Hide` to collapse. Toggling does not
  re-call the provider.
- `owner_prefs(id PRIMARY KEY CHECK (id=1))` single-row table for
  the owner's saved target language. Keeps `OWNER_DISCORD_ID`
  env-as-identity rule intact (env says "is owner?"; table stores
  prefs only).
- SQLite storage uses Compose named volume `bot-data` not a host
  bind mount, to dodge root-owned directory perms on first boot.

## Failed approaches / do not retry

- **Do not assume a "free tier" without checking signups are still
  open.** DeepL Free was the v1 plan; signups had already closed
  when M3 work started, surfaced by the user's screenshot, not by
  me. Recovery was clean only because the provider interface was
  in place.
- **Do not bind-mount `./data:/data` for SQLite in Compose
  without aligning ownership.** dockerd creates the host dir as
  root:root; the container's non-root `node` user can't write to
  it. Use a named volume that inherits image ownership.
- **Do not pass `sourceLanguage: undefined` when
  `exactOptionalPropertyTypes: true`.** Build a request literal
  that omits the property instead of including it as undefined.
- **Do not use `format=text` with naked numeric placeholders
  against Google MT.** Use `format=html` with `<span
  translate="no">⟦N⟧</span>` so the model preserves them, and
  HTML-escape the surrounding text accordingly.
